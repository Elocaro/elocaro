# Website

Statische Landingpage für Elocaro (`index.html`, `impressum.html`, `datenschutz.html`, gemeinsames `style.css`, `logo.svg`, keine Abhängigkeiten, helles und dunkles Farbschema, keine Cookies, nichts von Dritten). Sie wird **nicht** automatisch veröffentlicht.

Die Seite bekommt ein eigenes Hosting unter `elocaro.de`. Vor der Veröffentlichung:

- **Screenshots neu erzeugen:** Die Bilder zeigen noch die Oberfläche mit dem alten Produktnamen. Nach der Umbenennung der Anwendung neu aufnehmen und hier wie in `docs/bilder` ersetzen.
- **Repository-Adresse:** Die Links zeigen auf `https://github.com/elocaro/elocaro`. Das Repository ist dorthin umgezogen, aber noch privat; die Links laufen ins Leere, bis es öffentlich ist.
- **Logo:** `logo.svg` ist ein vorläufiger Entwurf (Haus mit E).
- **Kontakt:** Impressum und Datenschutz nennen derzeit eine bestehende Adresse unter `hahnsfamily.de`. Ein Postfach mit dem neuen Namen anlegen und eintragen, sobald die Domain feststeht.
- Impressum und Datenschutz rechtlich prüfen lassen; danach `noindex` entfernen.
- Den Abschnitt „Demo“ in `index.html` durch den echten Link ersetzen, sobald die Demo-Instanz läuft (#93).
- Angaben zu Wettbewerbern auf Aktualität prüfen.
