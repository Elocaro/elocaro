# Website

Statische Landingpage (`index.html`, `impressum.html`, `datenschutz.html`, gemeinsames `style.css`, keine Abhängigkeiten, helles und dunkles Farbschema, keine Cookies, nichts von Dritten). Sie wird **nicht** automatisch veröffentlicht.

Vor der Veröffentlichung (z. B. GitHub Pages oder ein eigener Webspace):

- In `impressum.html` und `datenschutz.html` die Angaben in eckigen Klammern eintragen (Betreiber nach § 5 DDG) und rechtlich prüfen lassen; danach `noindex` entfernen.
- Den Abschnitt „Demo“ in `index.html` durch den echten Link ersetzen, sobald die Demo-Instanz läuft (#93).
- Links auf das öffentliche Repository und die Branch-Namen prüfen (`blob/main/...` setzt den Standardzweig `main` voraus).
- Angaben zu Wettbewerbern auf Aktualität prüfen.
- Die Bilder sind Kopien aus `docs/bilder`; bei neuen Screenshots mit kopieren.
